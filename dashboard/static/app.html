⚙ Settings
News API key (currentsapi.services)
Optional — live news headlines from CurrentsAPI. Free tier: 250 requests/day. When set, JARVIS uses it first for news; without it, Gemini & DuckDuckGo handle news as before.
API access token (scripts / curl)
Optional — lets scripts and curl call the dashboard API without pairing. Requests then need Authorization: Bearer <token>. Leave empty to disable; saving a new value revokes nothing else. Session pairing via QR keeps working either way.
Phone pairing — talk to JARVIS from your phone
One-time key, valid 5 minutes. On the phone: scan the QR (or open the copied link in Chrome) → the dashboard opens, already logged in. Then tap 🎤 in the dashboard and just speak — your phone's microphone becomes JARVIS's ears, replies play on the phone. Nothing to install: any browser works. The phone stays paired after the key expires.

💡 Tip: install the dashboard as an app (⤓ button in the header, or Chrome ⋮ → Add to Home screen). The installed app keeps its own window, survives backgrounding much better, and reopens instantly from your home screen.
Push-to-talk (hold-to-talk hotkey)
Mark-LIV push-to-talk: while enabled, JARVIS's microphone stays closed unless you hold Ctrl+Space on the PC (or the on-screen hold button in the desktop app). Nothing is streamed while the key is up — even in wake-word mode.
Gemini one-shot client (side calls)
All one-shot Gemini calls (summaries, tool side-requests) walk one ladder: the Live model first — it draws on a separate quota pool from the text models — then pinned REST models, then -latest aliases. A rung that answers 429 is skipped for 5 minutes; CLEAR COOLDOWNS retries it right away.
